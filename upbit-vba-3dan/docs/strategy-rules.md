# 전략 규칙 요약 (3단정렬법)

## 역할
| 봉 | 역할 | 질문 |
|----|------|------|
| 15분 | 방향(나침반) | 위 / 아래 / 옆? |
| 5분 | 자리(지도) | 눌림자리가 가까워졌나? |
| 1분 | 트리거 | 지금인가? |

## 핵심 규칙
- 15분이 **Down이면 매수하지 않음**. Side도 기본 스킵(상승만).
- 1분 신호만 보고 진입하지 않음. 상위 봉과 정렬될 때만.
- **봉 중간 진입 금지.** 1분봉 마감 3초 전(초 ≥ 57)에만 판단.
- 판단 시 체크: 캔들 방향 · 상위봉 정렬 · 호가창 반대물량.
- 통과 시 봉 마감/다음 시가에 **시장가 매수**(롱만).

## 구현 모듈 매핑
- `modTrend15` → 15m HH/HL
- `modZone5` → 5m 눌림(저항→지지)
- `modTrigger1` → 1m 저점 후 양봉 전환
- `modHoga` → ask/bid 벽 비율
- `modStrategy` → :57 게이트에서 일괄 평가
- `modRisk` / `modOrders` → 손절·익절·체결 로그
