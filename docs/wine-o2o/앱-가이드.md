# CellarMatch 모바일 앱 가이드

구현 경로: `/wine` (로그인 없이 이용)

## 핵심 불변식

추천 결과 = 선택한 매장 재고(`qty > 0`) ∩ 테마·가격·페어링 필터

## 화면 흐름

1. `/wine` — 브랜드 히어로 + 매장 선택  
2. `/wine/[storeId]` — 테마 / 가격 / 페어링 큐레이션  
3. `/wine/[storeId]/results` — 재고 한정 추천 리스트  
4. `/wine/[storeId]/w/[sku]` — 상세 · 진열 존 · 위시  
5. `/wine/[storeId]/wishlist` — 매장별 위시리스트  
6. `/wine/kiosk/[storeId]` — 매장 키오스크 터치 모드  

## 로컬 실행

```bash
npm run dev
# http://localhost:3000/wine
```

## 샘플 데이터

- 매장 3곳 (`S001`~`S003`), 와인 12종, 매장별 재고(일부 품절 포함)
- 추천 엔진·불변식 테스트: `npm test` (`lib/wine/recommend.test.ts`)
