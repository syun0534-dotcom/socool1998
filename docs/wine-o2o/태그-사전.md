# 태그 사전 (부록) — 테마 · 페어링 · 가격대

**적용 규칙:** 태그는 WineMaster(또는 매장 오버라이드)에 붙지만, **고객에게 보이는 후보는 항상 `StoreInventory.qty > 0`인 SKU만** 남긴다.  
태그 커버리지 KPI: 파일럿 매장 SKU의 80%+에 테마 1개 이상 · 페어링 1개 이상.

---

## 1. 가격대 (PriceBand)

매장 판매가(`StoreInventory.price`) 기준. 통화: KRW.

| ID | 라벨 | 범위 (원) | 가이드 |
|----|------|-----------|--------|
| `price_entry` | 입문 | 0 ~ 25,000 | 데일리·입문 |
| `price_everyday` | 데일리 | 25,001 ~ 40,000 | 평소 한 병 |
| `price_gift_light` | 가벼운 선물 | 40,001 ~ 60,000 | 집들이·가벼운 기념 |
| `price_gift_std` | 표준 선물 | 60,001 ~ 100,000 | 생일·승진 기본 |
| `price_premium` | 프리미엄 | 100,001 ~ 200,000 | 격식·특별 |
| `price_icon` | 아이콘 | 200,001+ | 컬렉터·초격식 |

**UX:** 슬라이더 또는 칩. 다중 선택 시 OR.  
**랭킹:** 선택한 밴드 중앙값에 가까운 가격 가산점.

---

## 2. 테마 / 기념 (Occasion Themes)

| ID | 라벨 | 설명 | 추천 힌트 |
|----|------|------|-----------|
| `th_birthday` | 생일 | 축하·밝은 분위기 | 스파클링·프루티 레드/화이트 |
| `th_promotion` | 승진·취임 | 격식·리스펙트 | 무난한 프리미엄, 유명 산지 |
| `th_housewarming` | 집들이 | 부담 없는 선물 | 입문~가벼운 선물 밴드 |
| `th_date` | 데이트 | 로맨틱·부담↓ | 스파클링·라이트 바디 |
| `th_dinner_guest` | 손님 초대 | 테이블 와인 | 페어링과 조합 |
| `th_thanks` | 감사·인사 | 무난·품위 | 표준 선물 밴드 |
| `th_holiday` | 명절·연말 | 시즌 선물 | 패키지·인지도 |
| `th_valentine` | 발렌타인·화이트데이 | 시즌 | 스파클링·로제 |
| `th_everyday` | 오늘 한 잔 | 데일리 | 가성비 |
| `th_beginner` | 입문 추천 | 실패 최소화 | 당도·산도 완만 |
| `th_collect` | 셀러·보관 | 중장기 | 프리미엄+ |

**매핑 가이드**

- SKU당 테마 1~3개 권장 (과다 태그 금지)
- 시즌 테마(`th_holiday`, `th_valentine`)는 노출 캘린더로 on/off
- 매장은 로컬 테마를 `th_local_*`로 추가 가능 (파일럿 후 표준화)

## 5. 랭킹 룰 (MVP 단순안)

가중치 합으로 정렬 (가정, 파일럿 후 조정):

| 신호 | 가중 |
|------|------|
| 선택 테마 매칭 | +3 / 태그 |
| 선택 페어링 매칭 | +3 / 태그 |
| 가격 밴드 내 | +2 (밴드 중앙 근접 +0~2) |
| 입문 테마 시 완만 프로필 | +1 |
| 재고 수량 여유(과재고 소진) | +0~1 (매장 옵션) |
| 슬로우 무버 부스팅 | 어드민 플래그 시 +1 |

동일 점수면 가격 오름차순 또는 매장 지정 우선순위.

---

## 6. 콘텐츠 운영 체크리스트

- [ ] 신규 SKU 입고 시 테마 1+ · 페어링 1+ · 타입 필수  
- [ ] 가격 밴드는 가격 변경 시 자동 재계산  
- [ ] 시즌 테마 노출 일정 등록  
- [ ] 월 1회: 태그 없는 재고 SKU 리포트 → 보완  
- [ ] 스폰서 태그 도입 시 `sponsored` 플래그와 일반 테마 분리  

---

## 7. 예시 쿼리

**요청:** 매장 `S001`, 테마 `th_promotion`, 가격 `price_gift_std`, 페어링 없음  

**처리:**

1. `Inventory(S001) where qty > 0`  
2. `price in 60,001~100,000`  
3. `themes contains th_promotion`  
4. 랭킹 후 top 5 반환  

**결과 SKU는 모두 S001 매장 선반(또는 창고 판매 가능 재고)에 존재해야 함.**
