## 앱 바로가기

개발 서버 실행 후 **[/wine](/wine)** — 로그인 없이 매장 선택 → 테마 추천(재고 한정)

## 핵심 원칙

> **추천 = 매장 재고 ∩ 큐레이션 필터**
