# MVP 기능 백로그 (MoSCoW)

**제품 불변식:** 모든 고객향 추천·검색·테마 결과는 `storeId`의 `qty > 0` 재고에 한정한다.

범례: **M** Must / **S** Should / **C** Could / **W** Won’t (이번 MVP)

## E. MVP 범위 컷 라인

**MVP에 포함 (M만 + 필수 S 일부)**

- 매장 선택 → 테마·가격·페어링 → **재고 내 추천** → 상세·진열 존  
- 키오스크 웹모드(매장 고정)  
- 어드민 재고·태그·CSV  
- 기본 세션 로그  

**MVP 제외**

- POS 실시간, 결제, 스폰서, 네이티브 스토어 앱, 배송

## F. 사용자 스토리 (핵심)

1. **소비자:** 매장 X를 고른 뒤 “승진 선물·5만원대”를 고르면, X에 있는 병만 본다.  
2. **방문객:** 키오스크에서 “스테이크”를 고르면 재고 있는 페어링 와인과 선반 위치를 본다.  
3. **오너:** CSV로 재고를 올리면 앱·키오스크 추천이 그 수량 기준으로 바뀐다.  
4. **시스템:** 수량이 0이 되면 모든 고객 화면에서 해당 SKU가 사라진다.
